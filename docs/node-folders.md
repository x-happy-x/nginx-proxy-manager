# Свои папки узлов и отображение каскада

NPM-123, Core/VPN1.6.124. «Маршруты → Группы и узлы → Узлы»: «Новая папка», имя и выбор любых узлов из любых подписок. Группировка «Мои папки» показывает сохранённые папки; узел может быть в нескольких. Редактирование доступно карандашом в заголовке, также из панели маршрута. Поддерживаются переименование, добавление/удаление найденных, удаление папки с подтверждением, поиск папки и числовая сортировка узлов внутри неё. Узлы вне папок собраны отдельно.

Папки хранятся на роутере `/opt/etc/homenet/mihomo/node-folders.json`0600, входят в каталог данных VPN и доступны с других устройств через существующую авторизацию HomeNet. `/api/core/node-folders` GET/POST использует revision/CAS; конфликт возвращает409 и обновляет сведения перед повтором. Запись сериализована и атомарна. Повреждённый файл не затирается. Проверяются ID, уникальное имя1..80символов, пределы100папок/2000узлов в папке/20000участников суммарно. Недоступные/переименованные подпиской узлы сохраняются и явно помечаются; пользователь может удалить их сам. Секреты в папках отсутствуют.

Папки не создают группы Mihomo и не изменяют сетевые правила или выбранный выход. `pathOf` теперь включает транспортный dialer-proxy перед конечным выходом, например ИИ → Каскад Казахстана → выбранный вход → Казахстан · VLESS. Последний элемент остаётся конечным выходом, что сохраняет учёт «через этот узел». Деталь сервера показывает подключение; панель автоматического каскада использует результаты полной проверки из MIHOMO-27, а не общий пинг входа.

Проверки: Go suite, race-тесты хранилища (CAS, конкурирующие записи, сохранение неизвестных узлов, валидация, повреждённый файл); node-path tests (группы, каскад, циклы, последний выход); TypeScript, сборки amd64/arm64. UI desktop1280/mobile390 обе темы: создание из нескольких источников, редактирование/переименование, bulk add/remove, повторное имя, пустая папка и удаление, поиск, порядок31→104→531, сохранение после reload, недоступный сохранённый узел, полный путь. Browser console без ошибок. Скриншот изолированного тестового UI `.local/NPM-123-folders.jpg`.

Выкладка из merged master: `python scripts/deploy-node-folders.py --apply`. Обновляются только Core/VPN, проверяются staging hashes, lifecycle и readiness, предусмотрен откат. Mihomo MIHOMO-27 и [автоматический каскад](kz-cascade-repair.md) установлены отдельно; дальнейшая выкладка папок не меняет config.yaml.
