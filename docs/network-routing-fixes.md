# Рабочие узлы в режиме белых списков

NPM-106. Группы «Обходы», «ИИ обходы» и проверки отдельных адресов принимают
все подходящие узлы подписок, включая узлы без слов `обход`, `LTE`, `whitelist`
в имени. Их работоспособность определяют адаптивные проверки текущего режима
сети и проверка адреса самой группы. Исключения мусорных узлов и ограничения
стран ИИ сохраняются. Метки ограниченного трафика по-прежнему исключают такие
узлы из прямых групп и каскада.

Перед исправлением на действующем whitelist-uplink вне «Обходов» оставались
рабочий PAUK EU node-06 и семь узлов VPNUS. Изменение генератора и справки
поставляется в VPN 1.0.23. При применении к текущему конфигу удаляется только
`filter` у «Обходов», «ИИ обходов», Headscale и Keycloak; все остальные поля
сохраняются.

`config/lognex-test-schema.yaml` содержит отдельную группу для запрошенного
XSD на `apps-api-apps-5.testms-test.lognex.ru`. HTTP отдаёт редирект на HTTPS.
Проверка идёт по точному HTTPS-адресу схемы со статусом 200, а не по общей
странице проверки сети. При диагностике DIRECT и выбранные обычные VPN
давали таймаут, а OLCRTC отвечал. Правило ограничено этим именем хоста.

Выкладка: приватная копия `/opt/etc/mihomo/config.yaml`, сравнение исходного
хэша, проверка кандидата установленным `mihomo -t`, атомарная замена, горячая
загрузка `PUT /configs?force=false`. Фрагменты дополняют существующие группы
и правила; не заменять ими полный конфиг. Применять из master по запросу.
