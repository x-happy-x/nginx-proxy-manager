# Две группы игр — NPM-116

`Игры` сохраняет прежний выбор DIRECT → Обходы → AUTO. `Игры вне РФ`
принимает Null's, Supercell/Brawl и Roblox из прежнего inline `games_custom`,
включая IP 135.125.37.166, 155.212.214.229 и 155.212.214.234.
Прочие записи games_custom и общая категория игр остаются в `Игры`.
Точный игровой IP применяется раньше общего запрета UDP/443 и правил РФ.

Новая группа использует исходные подписки с adaptive-проверками стран
выхода, без DIRECT и вложенных групп AUTO/РФ. Страна определяется по
IP выхода; RU и неизвестные страны запрещены. Для UDP выбирается
подходящий поддерживающий его узел. При отсутствии разрешённого выхода
используется REJECT. Требуется ядро с `strict-exit-countries` (MIHOMO-24).

`scripts/split-game-routes.py` читает JSON-представление конфига из stdin
и выдаёт обновлённый JSON. `--patch` выдаёт только proxy-groups,
rule-providers и rules для применения через yq с сохранением остальных
узлов YAML. Повторное применение не дублирует группы и правила.

Перед установкой сохранить приватную копию исходного YAML, бинарника и
состояния API. Проверить кандидата установленным новым бинарником через
`mihomo -t`, сравнить исходный SHA256 перед заменой и загрузить конфиг
через локальный `PUT /configs?force=false`. Скрипт updater Re:filter должен
использовать основной config.yaml (XKEEN-3).

Проверка преобразования: `python scripts/split-game-routes.test.py`.
Сеанс настоящей игры проверяется на клиентском устройстве; успешная
проверка UDP-прокси сама по себе не подтверждает вход в игровой бой.
