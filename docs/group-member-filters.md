# Список участников группы и одна группа ИИ

NPM-121. В боковой панели группы на вкладке «Маршруты → Группы и узлы» добавлены порядок группы / пинг / имя, «Только отвечающие», поиск и счётчик результатов. Параметры сортировки и фильтра сохраняются в браузере и не меняют выбор узла или порядок fallback. При сортировке по пингу неотвечающие, непроверенные и временно снятые участники уходят в конец. Номера — исходный приоритет группы.

Конфиг упрощается скриптом ai-single-group.py до одной ручной группы «ИИ» и одного статического узла «Казахстан · VLESS». Вход каскада — существующая группа «Обходы», конечный VPS38.180.37.198. Альтернативы выбираются вручную среди серверов подписок. Автоматического перехода на другой VPS в группе ИИ нет. Удаляются пять вспомогательных групп ИИ и дубли direct/cascade, ссылки правил возвращаются на «ИИ».

В приватном routing.json сохраняется single_ai_group=true. В этом режиме генератор сохраняет ручной selector «ИИ» и не воссоздаёт «ИИ прямые/обходы». Проверяется наличие ручной группы; обычный режим других установок остаётся прежним. UI передаёт настройку обратно при применении остальных параметров.

Сборка: node scripts/build-modules.mjs arm64 1.6.122 --only=vpn. После merge в master: python scripts/deploy-vpn-members.py --apply. Обновляются Core и VPN через lifecycle с readiness и возвратом старых версий при ошибке. Затем merged scripts/ai-single-group.py устанавливается на роутер в /opt/etc/mihomo/recovery-NPM-121/apply.py и запускается /opt/bin/python3 <путь> apply. HomeNet проверяет mihomo -t и SHA, создаёт backup. Watchdog420s возвращает прежние три секции и флаг маршрутизации без confirm. После сетевых проверок запустить confirm. Для ручного отката предусмотрен rollback. Секреты остаются только на роутере.

Проверено до выкладки: go test ./..., TypeScript и сборки amd64/arm64; регрессионный тест сохранения одной ручной группы при повторной генерации. Преобразование действующего конфига идемпотентно, сохраняет остальные группы/секции и входные данные. UI принят в desktop1280 и mobile390, тёмной/светлой темах: числовой порядок31→75→80→...→1500, сохранение исходных номеров и текущего пути, поиск+фильтр с пустым результатом, сохранение предпочтений после reload.
