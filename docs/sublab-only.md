# Только подписки Sub Lab (NPM-102)

Миграция удаляет старые источники `ROUTER`, `CHAIN`, `AI` и группу
«Каскад». Их ссылки в группах заменяются подключёнными источниками Sub Lab.
Пять выбранных подписок, их фильтры, параметры подключения и интервалы
проверок сохраняются. Отдельные транспорты OLCRTC и Tailscale, DNS и правила
маршрутизации сохраняются.

`scripts/sublab-only.mjs` экспортирует чистую функцию `sublabOnly(config,
routing, sublab)`. Входы — разобранный YAML mihomo, `routing.json` и
`sublab/state.json`. Возвращает новые объекты и сводку без секретов.
Состояние маршрутизации переводится на крупнейшую оставшуюся подписку,
каскад отключается; из выбора групп Sub Lab удаляется исчезнувшая группа.
Модуль не подключается к устройствам и не применяет настройки.

Перед применением на устройстве:

1. Прочитать три входа и текущие выборы групп. Не записывать секреты в git.
2. Подготовить кандидаты и приватные резервные копии трёх файлов.
3. Проверить неизменность всех остальных секций и запустить установленный
   mihomo с `-t -d /opt/etc/mihomo -f <candidate>`.
4. Сравнить исходные хеши, заменить файлы атомарно, выполнить штатный
   `PUT /configs` с путём активного YAML. При ошибке восстановить все три
   файла и перезагрузить исходную конфигурацию.
5. Проверить состав провайдеров, рабочие группы, DNS и HTTP через прокси.
   Сохранить прежний выбор селекторов, если выбранный вариант ещё существует.

Проверка преобразования: `node --test scripts/sublab-only.test.mjs`.
