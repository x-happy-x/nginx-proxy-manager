# Категории узлов

NPM-122, Core/VPN 1.6.123. На странице «Маршруты → Группы и узлы» три вида: маршруты, узлы и диагностика по адресам. Узлы можно показывать карточками или таблицей.

Группировка по умолчанию: собственные узлы, затем каждая подписка. Название подписки берётся из безопасного поля `source` в `/api/core/nodes`: это отображаемый additional-prefix провайдера без завершающих разделителей. Если префикса нет, показывается идентификатор провайдера. Данные доступа не читаются в метаданные.

Другие варианты — страны и плоский список. Страны следуют настройке флагов (проверенный выход / имя); неизвестные честно собраны отдельно. Категории показывают отвечающие/всего. Собственные узлы и категория текущего участника изначально открыты, остальные свернуты. Раскрытие сохраняется отдельно для каталога и участников маршрутов в браузере. Поиск раскрывает все совпадения. Сортировка сохраняется внутри категорий; плоский список позволяет сравнивать пинг всех участников сразу. Длинные категории раскрываются кнопкой «Показать все».

Категории есть в каталоге и в панели выбора участника. Один список маршрутов заменяет ряд фильтров. Известные технические группы (AUTO, ALL, GLOBAL, прямые EU/мир, обходы, каскад, резерв и QUIC) доступны в раскрываемом блоке «Подключение и диагностика». Незнакомые пользовательские группы остаются на виду. Поиск или переход по текущему пути открывает техническую группу.

Это представление данных: конфиг Mihomo, правила, выбранные выходы, приоритеты fallback и каскад не переписываются. Номера в fallback остаются исходными. Одна группа ИИ и Казахстан · VLESS сохраняются.

Проверено: `go test ./...`; TypeScript и сборки amd64/arm64; desktop 1280 и mobile 390 в обеих темах; подписки/страны/неизвестная страна/плоский список; поиск подписки, числовая сортировка, фильтр отвечающих, раскрытие 22 участников, выбор узла и обновление пути на изолированной fixture, сохранение предпочтений после reload. Ошибок browser console нет. Fixture `scripts/fixtures/vpn-nodes.mjs` не обращается к живым устройствам.

Выкладка из merged master: `python scripts/deploy-node-categories.py --apply`. Обновляет только Core/VPN через lifecycle, проверяет staging hashes/readiness и предусматривает rollback. Перед/после сравнивается SHA-256 `/opt/etc/mihomo/config.yaml`, проверяются одна группа ИИ, текущий выход и доступность остальных сервисов. Скрипт без `--apply` только показывает план.
