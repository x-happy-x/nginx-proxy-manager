# ИИ через новый OLCRTC VPS

NPM-119. Сервер `88.214.53.84`, имя в HomeNet — `AI-88.214.53.84`.
Установка выполняется штатным мастером OLCRTC: SSH-ключ HomeNet, серверная
сборка совместимой версии, systemd, подбор Jitsi и локальное UDP-реле.
Пароль SSH и ключи туннеля в репозиторий не сохраняются.

`scripts/ai-olcrtc-route.py --patch` принимает приватный JSON текущего Mihomo
и возвращает секции для HomeNet `/api/core/config/{check,apply}`. Передавать
их в `set` вместе с актуальным `sha`; сначала выполнить check. Не печатать
исходный конфиг, patch или ответы с YAML в общедоступные журналы.

- `ИИ · сервер` — ручной переключатель. Основной выбор —
  `ИИ · OLC 88.214.53.84`; доступны прежние группы и отдельные узлы подписок.
- `ИИ · OLC 88.214.53.84` автоматически выбирает только варианты этого VPS
  из файлового провайдера `olcrtc`. Страна-флаг и название Jitsi могут меняться;
  фильтр привязан к уникальному имени сервера. При пустом списке — `REJECT`.
- Все существующие правила с целью `ИИ` переводятся на `ИИ · сервер`.
  При отказе нового VPS другой сервер автоматически не выбирается.

Выбрать другой сервер можно вручную в HomeNet, VPN → группы → `ИИ · сервер`.
Для возврата выбрать `ИИ · OLC 88.214.53.84`. После первого применения явно
выставить этот выбор через API групп: сохранённый выбор из cache.db может
иметь приоритет над порядком списка. `profile.store-selected` сохраняет выбор.

Обе новые группы имеют собственные имена, которые генератор маршрутизации
HomeNet не пересоздаёт. Правила ИИ с новой целью также сохраняются при сборке
маршрутизации; изменения подписок сохраняют провайдер `olcrtc`.

Проверки: конфигурация принята `mihomo -t` через HomeNet; сервер и варианты
видны в HomeNet; выход через новый VPS подтверждён; HTTPS запросы к ИИ
совпадают с правилами и цепочкой новой группы; проверен UDP и доступ к
домашним/корпоративным сервисам. Авторизованные сессии всех ИИ-провайдеров
и их индивидуальные ограничения аккаунтов сетевыми пробами не проверяются.

Приватная исходная копия на роутере:
`/opt/etc/mihomo/recovery-NPM-119-20261109`. HomeNet при применении создаёт
дополнительную `.homenet-backup-*.yaml`; откат конфигурации также проводить
через HomeNet, сохраняя текущий secret контроллера.
