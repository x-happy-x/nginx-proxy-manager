## Исправления и ограничения

- `chat.deepseek.com` исходно шёл через MATCH / «Остальное». Добавлено правило
  DOMAIN-SUFFIX для deepseek.com перед category-ai. Страница входа теперь
  открывается через ИИ/KZ. Сам вопрос требует входа пользователя.
- Для приложения Copilot добавлено правило
  m365copilotapp.svc.cloud.microsoft. Соединения
  cr.m365copilotapp.svc.cloud.microsoft подтверждены через ИИ/KZ.
  Отправку вопроса блокирует выбор персонализации рекламы в приложении;
  его оставили пользователю. Браузерный copilot.com также идёт через ИИ,
  но требует входа. Нельзя считать эти два сервиса проверенными до ответа ИИ.
- Desktop ChatGPT Work после перезапуска показывал ошибку загрузки настроек
  рабочей области. Повтор через браузер ответил; маршрут OpenAI-доменов был
  правильным. Причина ошибки Work этой проверкой не установлена.
- Во время длительной проверки обнаружено зависание проб каскада после
  44 кандидатов и последующий REJECT из-за истечения TTL. Исправлено в
  MIHOMO-29: deadline и отмена закрывают пробный поток до вложенного handshake.
  Регрессионный тест падает на прежнем коде и проходит с исправлением.
  Новое ядро прошло все 267 кандидатов и продолжало обновлять результаты;
  автоматический вход сохранялся, без закрепления конкретного узла.
